# Prime Hospital V2

Planned production features: offline-first OPD, universal Tab navigation, dark low-glare theme, colourful quick buttons, editable templates, free local drug bank, patient timeline and old prescription printing, vitals/BMI, Marathi instructions, Wi-Fi printing, billing, queue, reports, local/cloud backup and Supabase sync.

This file records the approved product direction and is intentionally kept separate from the clinical code while V2 is implemented incrementally.
